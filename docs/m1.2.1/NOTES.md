# M1.2.1: Animation refinement notes

The evidence in this folder was generated by `npm run visual -- --url http://localhost:3100 --out docs/m1.2.1`, with 20/20 checks passing. The exception is `m1.2.1-recording.webp`, a 16 s demo recorded separately with the same driver.

## Results

| Task | Outcome |
| --- | --- |
| 1. Engineering focus | The camera zoom is now **1.09×** (was 1.15×). Station info replaces the hero heading in the same slot; the "INSIDE MY LAB" eyebrow stays. The globe is no longer covered. Back to Lab, Escape, focus management and reduced motion all pass. |
| 2. Globe orbit | Rest is very subtle (container opacity 0.55). Hover or keyboard focus on Educational raises it to 1.0 over 450 ms and fades back over 700 ms. Measured over the highlight pixels, the mean lift is about 8/255 at rest and about 21/255 on hover. Same mask, geometry and 20 s lap as before. |
| 3. Energy flow | Unchanged. Re-verified: pulses still travel, and only the Engineering connection stays active during focus. |
| 4. Visual tooling | `scripts/visual/` (`npm run visual`), with no dependencies. The in-browser diff reproduces the earlier Python numbers exactly. |
| 5. Favicon | `app/icon.svg` and `app/favicon.ico` (16/32/48) for browser tabs, plus `app/apple-icon.png` (180) for iOS, all from the A monogram. `/favicon.ico` now returns 200. |

## Regression

See `regression.txt`.

- Idle vs M1.1: max difference 2/255, with no pixel above 2.
- Return-to-Lab vs idle: max 0 (identical).
- Reduced-motion idle vs M1.1: max 2/255.

## Camera sharpness

Laplacian variance on the laptop region, relative to native: 1.09× keeps **90%** of native detail, compared with 69% at 1.15× in M1.2. The remaining softening is the source plate's 1672 px limit.

## Shortcomings

- **The hover glow mixes two effects.** It also lights the Educational platform; that warm hotspot glow already existed in M1.1. On hover, the orbit halo also casts a soft warm spill onto the island edge next to the ring. Both are restrained, but they are not purely "ring only".
- **The camera can barely re-centre.** At 1.09× the shot can shift the scene only about 75 px sideways without exposing an edge. It reads as a push toward the station, not a re-centring. A stronger move needs a wider or higher-resolution plate; it is a background-rendering limitation.
- **Back to Lab sits above the server rack.** In focus it is at about y = 340, just above the rack at left. It's legible, but it is close to the artwork.
